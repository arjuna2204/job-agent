How it works

The filings already say what changed. Most people never read them.

Earnings Intel reads them for you and puts the changes next to the numbers.

1Pull the filings10-Ks, 10-Qs and earnings calls come straight from SEC EDGAR.
2Find what changedNew risks, shifts in guidance and tone between any two quarters, each linked to its source.
3Do the analyst mathAdjusted earnings, peer benchmarks and a DCF with bull, base and bear cases.
4Update every dayAn automated pipeline refreshes prices and filings each night.
Why it's different

Built for the question after "what's the price?"

Quote sites are great for prices and charts. Earnings Intel is for understanding the story behind them.

Frequently asked questions

Is it finished?
Not yet. The beta is live and updates daily, and new features are still being added.
Is this investment advice?
No. It's a research tool that organizes public filings. Always do your own research.
What is it built with?
Next.js, Python, Supabase, the Claude API and GitHub Actions, on data from SEC EDGAR. The code is open on GitHub.
Who built Earnings Intel?
